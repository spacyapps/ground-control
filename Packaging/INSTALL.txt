Ground Control — alpha
======================

1. Drag GroundControl.app to your Applications folder.

   It is signed with a Developer ID and notarised by Apple, so it opens on a
   double-click. No right-click, no warning, and it works offline.

2. Wire up your agent CLI.

   Easiest: click the menu-bar icon and choose "Set Up Hooks…".

   Or from Terminal, if you prefer:

      /Applications/GroundControl.app/Contents/Resources/install-hooks.sh

   Either one installs the `cc-notify` emitter to
   ~/Library/Application Support/GroundControl/bin/ and registers it in
   ~/.claude/settings.json — and ~/.cursor/hooks.json if Cursor is installed.
   It MERGES: hooks you already have keep working, and each file is backed up
   first. Safe to run again at any time.

   Claude Code and Grok both read the Claude settings file, so one run covers
   both. Restart Cursor afterwards if it was open; it reads hooks at startup.

   Later versions of the app update the installed emitter themselves on launch,
   so you only do this once.

3. Open a NEW terminal and start Claude Code or Grok.

   A CLI that is already running has not loaded the hooks. A row appears in the
   panel as soon as the agent does anything.

The panel lives in the menu bar — the ✦ icon. Click it to show or hide.


Uninstalling
------------

Menu-bar icon > "Remove Hooks…", then quit and drag the app to the Trash.

Order does not matter: a copy of the uninstaller is kept beside the emitter, so
if the app is already gone you can still run

   ~/Library/Application\ Support/GroundControl/bin/uninstall-hooks.sh

It unregisters only Ground Control. Hooks belonging to anything else are left
alone, and your themes are not touched — they stay in
~/Library/Application Support/GroundControl/Themes if you want to keep them,
or delete that folder to remove everything.


What to look at
---------------

- Clicking a row should jump to the terminal or editor that session is in.
  Terminal.app and iTerm2 land on the exact tab; VS Code, Cursor and the rest
  bring the app forward.

- A row turns RED when an agent is waiting on you. If you run Claude Code with
  permissions set to `auto`, it never stops to ask, so you will not see this —
  worth testing with the default permission mode.

- Right-click a row, or use the ☰ mark above the status dot, for the menu.

- Settings > Theme has two demo skins. Both are shaped windows; drag the
  bottom-right corner to resize.

- Settings > Panel > "Show the analyser" turns off the moving bars.


Known rough edges
-----------------

- Cursor's own agent (Composer) has LIMITED SUPPORT. Its chats appear as rows,
  named after the question they started from, and clicking one raises Cursor.
  But the red alarm cannot work there: Cursor fires no hook while its agent
  waits for you to approve something, so a blocked Composer chat looks the same
  as a busy one. Claude Code running in Cursor's TERMINAL is fully supported,
  alarm included.

- Codex and Gemini are not verified. Claude Code and Grok are.
- Sessions inside tmux, over ssh, or from a launchd job have no app to jump to,
  so clicking a row reveals the folder in Finder instead.
