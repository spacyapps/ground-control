Ground Control 0.8.0
====================

A menu-bar app that shows which of your AI coding agents is waiting on you.

   What it is, with pictures    https://www.spacyapps.com/apps/ground-control
   Source, and what works       https://github.com/spacyapps/ground-control

This file covers installing it. Everything else lives in those two places, so
they stay right when this file cannot.


1. Install
----------

Drag GroundControl.app to your Applications folder.

It is signed with a Developer ID and notarised by Apple, so it opens on an
ordinary double-click — no right-click, no trip to System Settings. The first
launch asks "are you sure you want to open it?", which macOS asks of anything
downloaded from the internet. Click Open; you will not see it again.

It makes no network connections of any kind, and works offline.


2. Connect your agent
---------------------

Click the menu-bar icon and choose "Set Up Hooks…".

Or from Terminal:

   /Applications/GroundControl.app/Contents/Resources/install-hooks.sh

It finds the agents you have — Claude Code, Grok, OpenAI Codex, Cursor,
opencode — and registers with each. It MERGES: hooks you already have keep
working, every file is backed up first, and it is safe to run again. Later
versions update the emitter themselves, so this is a one-time job.

Two things that catch people out:

 * CODEX ASKS PERMISSION TO RUN HOOKS AT ALL. The next time you start `codex`
   interactively, accept its one-time trust prompt. Until then no hooks run and
   no Codex rows appear. Nothing can click it for you.

 * RESTART WHAT WAS ALREADY OPEN. A CLI that is already running has not loaded
   the hooks. Open a new terminal; restart Cursor if it was open.

Then start an agent. A row appears as soon as it does anything, and clicking it
takes you to that session.


Which agents raise the alarm
----------------------------

Rows appear for every supported agent, but not all of them can tell you when
they are stuck — some never say so, and no app on this side can invent it.

The README has the full table, with the date and version each was tested
against, including the ones that do not work and why:

   https://github.com/spacyapps/ground-control#agents


Themes
------

One ships with the app. More are separate downloads — unzip one, then
Theme > Open Themes Folder… and drag the folder in. They are plain folders of
JSON and images, so they cost nothing to try and nothing to remove.

   https://www.spacyapps.com/apps/ground-control/themes


Uninstalling
------------

Menu-bar icon > "Remove Hooks…", then quit and drag the app to the Trash.

Order does not matter: a copy of the uninstaller sits beside the emitter, so if
the app is already gone you can still run

   ~/.groundcontrol/bin/uninstall-hooks.sh

It unregisters only Ground Control. Hooks belonging to anything else are left
alone, and your themes stay in
~/Library/Application Support/GroundControl/Themes — keep them, or delete that
folder to remove every trace.
